# Same Patient, Different Day

Interactive results for a counterfactual audit of the weekend effect in clinical language models.

**Live site:** https://parisarostaami.github.io/same-patient-different-day/

Each case is given to a model seven times with only the day of the week changed, so any change in the answer comes from the day alone. The site lets you run the twin test yourself, browse every synthetic case with the exact model inputs and outputs, and see the charts, the statistics and the checks against real hospital data.

**Data.** MIMIC-III, MIMIC-IV and eICU-CRD were used under PhysioNet credentialed access. This repository contains only aggregate results and synthetic cases. No patient-level data is included.
